Engine Features

OpenGL 4.3+

PBR rendering, shadow mapping, fog, and post-processing pipeline.

ECS Architecture

Entity Component System powered by EnTT for high-performance game logic.

C# Scripting

Managed gameplay scripting via Coral (.NET/CoreCLR interop).

Physics

Jolt Physics integration for realistic simulation.

Networking

UDP client/server with encryption and UPnP port forwarding.

Animation Graphs

Visual animation system with blend trees and state machines.
