Features

OpenGL 4.3+

PBR rendering, fog, shadow mapping, animation graphs.

ECS Architecture

EnTT-based entity component system for flexible scene management.

C# Scripting

Managed gameplay scripting via Coral (.NET/CoreCLR).

Physics

JoltPhysics integration for realistic simulations.

Networking

UDP client/server with UPnP port forwarding and encryption.

Project Export

Compressed asset packs (ZSTD) for easy distribution.
